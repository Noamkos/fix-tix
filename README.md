# FixTix: דמו

דמו של FixTix, פלטפורמה למכירה חוזרת של כרטיסים שעובדת עם חברת הכרטיסים: כל כרטיס נבדק מול החברה, ננעל בזמן שהוא למכירה, ובכל מכירה הברקוד הישן מבוטל ונוצר כרטיס חדש על שם הקונה. האפיון המלא (FIXTIX_SPEC.md) נשמר מקומית בלבד ולא עולה למאגר.

הכל רץ בדפדפן: אין שרת, אין בסיס נתונים, אין כסף אמיתי. DemoTix היא חברת כרטיסים פיקטיבית שמייצגת חברת כרטיסים אמיתית, וכל האירועים, האמנים והאנשים בדויים.

## להריץ במחשב

צריך Node.js מותקן. פעם ראשונה בלבד:

```bash
npm install
```

ואז:

```bash
npm run dev
```

ולפתוח את הכתובת שמופיעה (בדרך כלל http://localhost:5173).

## לפתוח בטלפון (באותה רשת Wi-Fi)

```bash
npm run dev:phone
```

בשורה `Network:` תופיע כתובת כמו `http://192.168.1.20:5173`. פותחים אותה בדפדפן של הטלפון. שימו לב: לטלפון יש דמו משלו, הוא לא רואה את מה שקורה במחשב (כי אין שרת שמחזיק את המידע במקום אחד).

## להציג בפגישה

1. נכנסים ל-`/admin` (או לוחצים על כפתור **Demo** בפינה השמאלית התחתונה של כל מסך).
2. **Reset the demo**: הכל חוזר לנקודת ההתחלה (כולל ארבעה שבועות של מכירות לדוגמה בלוח הבקרה).
3. **Start presentation mode**: המסך מתחלק לשניים, DemoTix משמאל ו-FixTix מימין.
4. בסרגל העליון בוחרים את שלב התסריט (‹ ›). כל שלב פותח את המסכים הנכונים ומחבר את המשתמש הנכון (Dana המוכרת / Nikos הקונה).
5. בסוף: **Reset**, ומוכנים לפגישה הבאה.

התסריט המלא, 10 שלבים, מופיע ב-`/admin`.

## להעלות לאינטרנט (Vercel)

הפרויקט מוכן ל-Vercel (הקובץ `vercel.json` כבר קיים). הדרך הפשוטה:

1. מעלים את התיקייה ל-GitHub.
2. ב-[vercel.com](https://vercel.com) בוחרים **Add New → Project** ואת המאגר.
3. Vercel מזהה Vite לבד. לוחצים **Deploy**, ומקבלים קישור קבוע להצגה.

לפני ההעלאה הראשונה ל-GitHub, לעבור על הקבצים (`git status`) ולוודא שאין בהם סיסמאות או מידע אישי. בפרויקט הזה כל הנתונים בדויים.

## איך זה בנוי

- **React + Vite + Tailwind**, מעבר בין מסכים עם React Router.
- כל המידע נמצא במאגר אחד (`src/store/store.js`), נשמר בזיכרון הדפדפן ומסתנכרן בין טאבים.
- נתוני ההתחלה: `src/data/seed.js` (אירועים, משתמשים, כרטיסים) ו-`src/data/history.js` (מכירות לדוגמה).
- הצד של חברת הכרטיסים: `src/demotix/` (שש פעולות הממשק ב-`api.js`, הסורק ב-`gate.js`).
- הצד של FixTix: `src/fixtix/` (מכירה, קנייה, החלפה, רשימת המתנה, לוח בקרה).
